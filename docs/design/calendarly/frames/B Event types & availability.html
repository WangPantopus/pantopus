Event types & availability

The bookable catalog — a list of rows mirroring List of Rows for the row primitive and A08 Support trains for the screen chrome. Each row is one bookable: a color dot, a name, a duration + location caption, and a right-aligned on/off toggle, with an overflow menu for copy-link / duplicate / share / hide / delete. The Personal variant reads sky, the Business variant projects the same list as priced services with assignee counts. Pillar color lives only on the identity pill and section overline — every functional control stays product blue.
