Event type / service editor

One form for create and edit, mirroring Form for field grouping and A13 Edit Business Page for the long sectioned settings form with a sticky save bar. Sections are white cards with overline labels — Basics, Duration, Location, Availability, Assignment (Business), a collapsible Advanced, Pricing & payment, and links-out. The editor reads owner_type to set the pillar; pillar color appears only on the header pill and the overlines, while every input, stepper, segment, toggle, and CTA stays product blue.

On save the bottom bar becomes a shimmer with "Saving…" and every field is disabled so nothing changes mid-write. The top-bar action reads "Saving".
