Add to calendar sheet

The surface that actually produces the calendar event promised across the confirmation screens — the RsvpCluster chips promoted to a full action sheet with a native EventKit write path. It slides up over any booking surface (invitee confirmed, host detail, home-event, visit) with a one-line event recap, then a vertical list of real labeled tap rows reusing the Gig Picker Sheets pattern (56px rows, leading icon disc, label + sub, trailing chevron, 1px dividers) — Apple Calendar, Google, Outlook, and Download .ics. Context-neutral chrome; the accent inherits the surface that opened it. Lucide icons, no emoji.
