Booking limits & notice rules

A bottom sheet over the dimmed editor. Each rule is a white card — a label, a one-line caption explaining the effect, and a numeric stepper with a unit suffix or a segmented control: minimum notice, how far ahead people can book, daily and weekly caps, a per-person limit, and where start times land in the hour. Mirrors Form.html for the field groups and A13 Edit Business Page for the numeric settings rows. Personal sky tints only the sheet overline — every control stays product blue. When a rule conflicts (the booking window falls inside the minimum notice) the field outlines in error red and Done disables.

Calm, sensible values
4 hours notice, book up to 60 days out, 8 per day, 20 per week, 2 per person, and :00-only start times. A helper notes you usually don't need to touch these.
2 · CUSTOM
Tightened limits
12 hours notice, 14 days out, max 3 per day, 1 per person, and :00 & :30 start times — the same fields dialed in for a busier calendar.
3 · CONFLICT ERROR
Window shorter than notice
"Book up to" set to 0 days outlines in error red with the message that no times will show, and Done is disabled until it's resolved.
