Embed widget settings

A web host-settings screen that surfaces the /book/[slug] flow onto external sites or the host's /b/[username] page. It mirrors the Edit Business Page block-editor — a left config column and a right live-preview pane — with the A14 settings-list rows and a code-snippet block. Business violet is the driving pillar: it's the widget's default brand color, shown in the preview's button and the brand swatch (a Personal sky variant is noted). Every functional control — the segmented type switcher, Copy snippet, toggles — stays product sky.
