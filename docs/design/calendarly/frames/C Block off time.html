Block off time

The host's quick "+ Busy time" action — the inverse of a booking. It drops an ad-hoc busy hold onto personal availability so the engine stops offering that slot; it does not create a bookable event and is not a whole-day date override. A reason (private to you), a date, an all-day toggle, a start/end time-range picker of real labeled buttons, and a repeats row. Mirrors A14.8 Vacation hold for the date-block frame, the A12.11 time-range picker for the window, and Form.html for the recurrence field group. Conflicts ride on a semantic warning chip — never a flood-fill or left-border. Personal sky tints only the sheet overline.
