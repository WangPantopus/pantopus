Pantopus · Calendarly · Terminal states

Unavailable / Expired / Paused / Secret states

ONE catch-all terminal screen for broken, paused, private, and expired booking, manage, and poll links — a single status-driven component that switches only its icon, headline, and body on the HTTP status code (reusing publicShare.ts's "not shareable" / notFound rendering). It mirrors the Support Train public layout verbatim: a centered muted icon halo, a reason headline, a one-line body in --fg3, and an identical Back-to-Pantopus + Get-the-app dock on every state. State-specific affordances (code input, request-a-new-link, host message + reopen date, notify-me, book-again) layer into the shared chrome. Neutral; the pillar color appears only on the Get-the-app CTA. This is a single route with a status switch — not separate routes per state.
