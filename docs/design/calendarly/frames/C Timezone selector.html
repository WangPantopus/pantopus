Pantopus · Calendarly · Timezone selector

Time zone

A searchable bottom sheet that opens when an invitee taps the timezone control on the slot picker — never a full screen. It mirrors the A14 searchable settings-list: a search field, a pinned Detected row for the device zone, and a Common list, each row a real labelled button showing the GMT offset and current local time. The selected checkmark uses the host's pillar (Personal sky here); every other control stays product sky. Changing the zone re-times the slots beneath.
