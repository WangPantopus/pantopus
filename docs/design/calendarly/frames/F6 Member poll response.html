Find a time · Member poll response

A member marks which proposed slots work, built on the existing Polls module with time-slot options. An organizer header frames the ask; each proposed time is a poll-style row with a 3-way Works / If needed / Can't control (green / amber / red). Personal conflicts are auto-flagged from the member's own calendar and pre-set to "Can't". Submit stays disabled until at least one slot is answered.
