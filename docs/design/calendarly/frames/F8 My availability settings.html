My household availability settings

A boundary screen that governs exposure only — it never edits the source availability. Matching the A14 settings-list pattern: a context header, a Personal-sky deep-link row to the source of truth, and toggle / disclosure rows for what this household sees (share free/busy, round-robin, quiet hours, auto-decline). A footnote makes the boundary explicit: this only controls what this household sees.
