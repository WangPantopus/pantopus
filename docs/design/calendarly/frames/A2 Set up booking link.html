Set up your booking link

The four-step first-run wizard that takes a host from zero to a shareable booking link in the fewest taps. Copies the Start a Support Train wizard pattern 1:1 — same numbered StepRail with check-on-done discs and 2px connectors — recolored from the warm support-train tone to the Personal sky pillar. Steps 2 and 3 each carry a "Use defaults" skip so they're one tap. The availability check runs live on the handle; the weekly-hours grid reuses the weekday + time-range button pattern; an auto-detected timezone chip never forces a step.

FRAME 1 · STEP 1 · DEFAULT
Claim your booking link
Monospace handle field prefilled with the slug; a live availability check returns a green "Available" chip with the reassurance line. Primary "Continue · pick a type" is enabled.
FRAME 2 · STEP 1 · CONFLICT
That link is taken
Handle field turns to the error border with an alert glyph; an inline error message and three monospace suggestion chips offer one-tap fixes. Continue is disabled until the slug resolves.
FRAME 3 · STEP 1 · LOADING
Checking availability
While the slug is verified the status row shows a shimmer chip + line in place of the result — never a "Loading…" string. Continue stays disabled until the check resolves.
FRAME 4 · STEP 3 · HOURS
Weekly hours + timezone
Auto-detected timezone chip the booker can tap to change. Mon–Fri rows are real labeled buttons showing "9:00 AM – 5:00 PM" with an enable toggle; weekends are off. "Use defaults" skips the step in one tap.
FRAME 5 · STEP 4 · SUCCESS
You're all set
A18 success hero: centered sky disc with a check, the live link in a copy card, primary "Share link" and a ghost "Add type" to define another event type. The StepRail reads fully complete.
FRAME 6 · RESUME
Pick up where you left off
Re-entered at step 3 with steps 1–2 checked in the rail and a resume banner. The host lands directly on the unfinished hours step to finish in one move.
