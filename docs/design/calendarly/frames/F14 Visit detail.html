Visit detail

One screen for a scheduled or pending visit, with the share/manage link folded in as a section. Mirrors EventDetail/SupportTrainDetail — a header card, an Offered → Reserved → Confirmed → Done status timeline, host members, an access note with an Access-codes link, and a Share & manage section (link, Copy/QR, slot summary, Revoke/Extend, preview). A confirmed visit writes a home calendar event. Nine states cover the visit lifecycle and the link lifecycle.
