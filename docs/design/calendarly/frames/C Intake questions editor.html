Intake questions editor

A bottom sheet over the dimmed event-type editor. Inside, a reorderable list of question rows (List of Rows) with the Form field-group idiom for add and edit. Name and email are locked defaults — always asked, no toggle, no drag. Custom questions carry a type caption, a Required pill, a drag handle, and a delete. Editing expands an inline field group: question text, a segmented answer type, a required toggle, and an options list for select types. The pillar (Personal sky / Business violet) inherited from the parent event type tints only the sheet title overline; every control stays product blue.
