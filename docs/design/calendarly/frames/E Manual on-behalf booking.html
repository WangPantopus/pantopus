Manual / On-Behalf Booking

A host or member creates a booking for someone else — phone-in, walk-in, front-desk. It mirrors the A12 wizard chrome from Start a Support Train: a top bar with back chevron and a slim step rail (Event type · Time · Details · Review · Booked), the current pill tinted in the active scope's identity color. Step 1 is an event-type picker; step 2 reuses the shared Support Trains availability grid (weekday strip + stacked slot-row buttons, never a dense grid) with a tappable timezone chip and a composed-availability explainer; step 3 is the invitee form with a neighbor search that pivots to an invite-by-phone / email branch when no verified neighbor matches; step 4 is a review summary with "Skip approval" and "Skip notifications" switches. The created confirmation reuses the A18 status screen.
