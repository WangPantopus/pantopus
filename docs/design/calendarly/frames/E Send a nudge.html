Send a Nudge / Manual Follow-up

A one-off manual message to an event's attendees — reminder, update, thank-you — with no saved workflow. A bottom sheet reusing the ManageTrain SendUpdateForm almost verbatim: a message textarea with a live character counter that turns red past the limit, a "Use a template" chip linking to the Template Library, single-select audience chips (All attendees / Confirmed only / No-shows, each showing its recipient count), and a Push / Email channel toggle row with Push default on. The sticky primary CTA echoes the recipient count — "Send to 12". This is the existing "Send an update" form pointed at a calendar/booking event.
