Pantopus · Calendarly · Payment recovery

Payment failed / retry state

A payment-failure recovery sheet for paid bookings that holds the slot while the invitee retries — preventing the "paid but lost my slot" nightmare. It slides up over /book/[slug]/review on a payment failure, leading with a clear, blame-free decline reason and a prominent slot-hold countdown so the reservation feels safe. The retry CTA re-opens the native Stripe PaymentSheet — never a hand-drawn card form — and the saved-card row reuses A14.6. Neutral error chrome; host pillar (Personal sky) only on the retry CTA. We never charge twice.
