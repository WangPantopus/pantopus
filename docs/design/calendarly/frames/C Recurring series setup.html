Recurring / multi-session setup

One decision that lays down many linked slots — "every Tuesday for 6 weeks" — distinct from a package credit wallet. It's a wizard step inserted into the invitee picker flow, between slot-pick and Review, when the event type allows recurrence. It reuses the Support Trains weekday + time-range grid and slot-row list for the per-occurrence rows, the Home calendar month strip to preview the series, and Review & Confirm for the summary recap. Host pillar (Personal sky) marks selected occurrences and the active CTA. Every occurrence is a real labeled button — day, date, time, status.
