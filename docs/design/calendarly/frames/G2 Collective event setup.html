Collective Event Setup

Configure a multi-staff "collective" service where several members must all be free for a slot. A Business-pillar bottom sheet off the Service Editor: a master "Require multiple staff" toggle (off collapses the rest), a required-staff stepper, an A12.11 two-tile selector (Specific members / Any N of a group), an A10.7 roster multi-select, a capacity-per-slot stepper, and an intersect explainer styled like A10.8's inline SLA note. Sticky primary Save. Violet pillar accent throughout; never sky.
